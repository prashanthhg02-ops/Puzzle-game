# Tile Quest

A small sliding-tile puzzle game that runs directly in your web browser. No installation or build step is required.

## Play

Open `index.html` in a modern browser, choose a puzzle size, and select **New puzzle** to start or reshuffle.

Click or tap a tile next to the empty space to slide it. You can also use the arrow keys to move tiles into the empty space.

## Features

- Easy (3 × 3), Classic (4 × 4), and Expert (5 × 5) puzzles
- Solvable randomized puzzles
- Move counter and timer
- Completion message when the tiles are in order
- Responsive layout for desktop and mobile
